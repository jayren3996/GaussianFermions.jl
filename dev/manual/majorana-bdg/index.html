Majorana / BdG Foundation

The Majorana layer handles general quadratic dynamics, including pairing (number-non- conserving) terms that the correlation-matrix layer cannot represent. States live in MajoranaState (the real antisymmetric covariance matrix $\Gamma$), and dynamics are generated by BdGHamiltonian and MajoranaLindblad.

States and correlations

using GaussianFermions

state = MajoranaState([1, 0, 1, 0])
normal_correlation(state)        # Cᵢⱼ = ⟨c⁺ᵢcⱼ⟩
anomalous_correlation(state)     # Fᵢⱼ = ⟨cᵢcⱼ⟩

Correlations follow the standard convention $C_{ij} = \langle c_i^\dagger c_j\rangle$, $F_{ij} = \langle c_i c_j\rangle$ with covariance $\Gamma_{ab} = \tfrac{i}{2}\langle[\omega_a, \omega_b]\rangle$ (verified against exact diagonalization).

Unitary BdG dynamics

BdGHamiltonian is built from a Hermitian hopping matrix A and an antisymmetric pairing matrix B, and evolves a MajoranaState's covariance:

A = zeros(ComplexF64, 4, 4)
B = zeros(ComplexF64, 4, 4); B[1, 2] = 0.3; B[2, 1] = -0.3

H = BdGHamiltonian(A, B)
evolve!(state, H, 0.5)

Ground and thermal states come from Bogoliubov / Nambu diagonalization:

gs = groundstate(H)              # BCS ground state as a MajoranaState
ε  = quasiparticle_energies(H)   # Bogoliubov spectrum (≥ 0)
ρβ = thermalstate(H; β=2.0)      # Gibbs state; β → ∞ recovers groundstate(H)

Open-system BdG dynamics

MajoranaLindblad is the covariance-matrix analogue of CorrelationLindblad. It supports particle loss / gain, occupation dephasing, and — unlike the number-conserving solver — general pairing baths via raw Majorana jump vectors:

H = hopping(4; pbc=true)
lind = MajoranaLindblad(H; loss_ops=[sqrt(0.3) * ComplexF64[1, 0, 0, 0]],
                        dephasing_ops=[(ComplexF64[1, 1, 0, 0] / sqrt(2), 0.5)])

state = MajoranaState(CorrelationState(SlaterState(L=4, N=2, config="Z2")))
evolve!(state, lind, 1.0)

density(state)
normal_correlation(state)
anomalous_correlation(state)     # nonzero once a pairing bath acts

dephasing_ops entries are (mode, rate) pairs. The master-equation right-hand side is exposed as majorana_lindblad_rhs.

On number-conserving channels MajoranaLindblad reproduces CorrelationLindblad to machine precision (see example/Dephase.jl).
