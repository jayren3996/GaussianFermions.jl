API Reference

This section documents the public API of GaussianFermions.jl, grouped by topic:

  • States & Spectra — SlaterState, CorrelationState, MajoranaState, BdGHamiltonian, quasi-modes, and ground / thermal states.
  • Hamiltonians — QuadraticHamiltonian, builders, and propagators.
  • Observables — densities, particle-number statistics, and entanglement diagnostics.
  • Dynamics — CorrelationLindblad, MajoranaLindblad, dissipation / measurement channels, and quantum-trajectory primitives.
